# Runtime 1.2.6

Update `sympress/runtime` with Composer and review the resulting lockfile.
Symfony DependencyInjection now requires 8.1.8 or newer, which preserves
environment placeholders reused after an earlier container extension overrides
the same value. The fix is the stable upstream change in
[Symfony PR 66434](https://github.com/symfony/symfony/pull/66434).

The repository does not publish a Composer lockfile. The public dependency
constraint therefore guarantees the fix for fresh and existing consumers after
dependency resolution. The standalone CLI reports version 1.2.6.

The later Process `SYMFONY_DOTENV_VARS` fix and Symfony 8.2
`resolvesAtCompileTime()` API remain upstream follow-ups. They are not part of
Symfony 8.1.8 and this release does not require unreleased dependencies.
