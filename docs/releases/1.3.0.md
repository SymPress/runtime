# Runtime 1.3.0

Runtime supports stable Composer 2.11 through the `^2.10.3` library constraint.
Composer 2.10.3 remains the minimum supported version. Composer 3 is excluded.

Existing projects can select the new stable library with:

```sh
composer update sympress/runtime composer/composer --with-dependencies
```

The compatibility gates exercise matching minimum and latest stable Composer
CLI/library pairs, including normal WordPress installation and standalone
package recovery. Release publication still requires the complete verified-tag
workflow.
