# Runtime 1.2.4

Update with `composer update sympress/runtime --with-all-dependencies`, commit
the lockfile and regenerate release artifacts with `vendor/bin/runtime` and
`vendor/bin/runtime dump-env production`.

Environment cache reads no longer invalidate OPcache. Only a successful changed
mutable cache write invalidates that file; immutable dumps and identical writes
remain compiled. The regression fixture performs 8,000 warm reads with a 16 MB
OPcache and timestamp validation disabled, then verifies changed-cache refresh.

Generated MU loader and kernel headers contain the installed Runtime version.
Regeneration resolves the missing-version inventory finding. This does not add
the private Security package or require its vulnerability gate in any project.

Doctor can run as PHP-FPM against a warmed immutable release owned by the deploy
user. The cache must be inside the project, owned by its release owner, readable
and unwritable by PHP-FPM, with an explicit immutable flag and build ID. External
cache roots and mutable cache maintenance still require the calling owner.
Group/world-writable directories and symlinks remain failures.
