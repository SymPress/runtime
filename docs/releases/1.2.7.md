# Runtime 1.2.7

Update `sympress/runtime` with Composer and review the resulting lockfile.
Absent optional environment files no longer leave a suppressed `stat()` warning
in PHP's `error_get_last()`. WordPress treated that leftover as a PHP error,
added the `php-error` admin body class and shifted the admin sidebar by 2em.

Environment cache signatures are unchanged: a missing path is still `null` and
existing files and directories keep their size and mtime signature, so no cache
needs to be rebuilt. The standalone CLI reports version 1.2.7.
