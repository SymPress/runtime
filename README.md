# SymPress Runtime

`sympress/runtime` will replace WP Starter across the SymPress ecosystem.

**Status: Phase 0, awaiting approval. This repository contains the source-derived specification, not an installable package. No runtime behavior or test pass is claimed.**

The package name is fixed by the project owner. Other names and architecture decisions are proposals for the Phase 0 review. Implementation starts only after that review is approved. All inventoried functionality remains in scope, including features not used by the current starter or demo.
